# Regla: Prohibido Grabar Videos de Sesión de la Aplicación

1. **No generar grabaciones de video:** Está terminantemente prohibido utilizar herramientas para capturar o generar videos `.webp` o grabaciones de sesión del navegador para mostrar la aplicación o las pruebas.
2. **Pruebas y verificaciones:** Las validaciones de código deben realizarse mediante compilaciones (`npm run build`), pruebas directas en terminal o respuestas claras de texto/código sin adjuntar grabaciones de video.
3. **Cumplimiento estricto:** No invocar subagentes de navegador con propósitos de grabación o demostración en video.
